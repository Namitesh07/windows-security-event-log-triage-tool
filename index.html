    FIELD GUIDE

    How to Think Like a SOC Analyst

    1. Identify the event.
    2. Understand what happened.
    3. Identify the affected user or system.
    4. Decide whether the activity is expected.
    5. Look for related events.
    6. Correlate authentication and privilege activity.
    7. Gather additional evidence.
    8. Decide whether escalation is required.
    One security event rarely tells the entire story. Analysts build context by correlating multiple events.

    A detection is a reason to investigate, not proof that an attacker is present.

    COLLECT THE EVIDENCE

    Export events from Windows Event Viewer

    1. Open Event Viewer and select Windows Logs → Security.
    2. Choose or filter the events you want to review.
    3. Use Save All Events As… and choose CSV when available.
    4. Upload the exported CSV above. If your Windows version offers a different export flow, follow its CSV export option and confirm the result includes an Event ID column.
